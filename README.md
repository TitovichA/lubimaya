# Любимая

Персональная система управления жизнью, привычками, дисциплиной и целями.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Сборка PWA

```bash
npm run build
npm run preview
```

## Возможности

- Утренний и вечерний ритуалы (безлимит пунктов, drag & drop)
- Постоянные привычки с сериями, категориями и графиками
- Задачи с приоритетами, подзадачами и повторениями
- Цели с прогрессом, этапами и автоматизацией от привычек
- Статистика, тепловая карта, календарь, заметки с файлами
- Жизненные проекты и панель баланса сфер
- Шаблоны дней, обзоры, поиск, ИИ-помощник
- Облачная синхронизация между устройствами (код в Настройках)
- Установка как PWA на iPhone, iPad, Mac и Windows
